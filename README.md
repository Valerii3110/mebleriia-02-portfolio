# 🌐 Mebleriia — Portfolio Landing

A clean, modern, and fully responsive portfolio landing page built to showcase UI/UX design, layout quality, and front-end development skills. Inspired by TailwindUI minimalism and Next.js documentation styling.

## ✨ Overview

This project represents a furniture-brand concept website called **Mebleriia**.
It focuses on a simple, elegant user interface, soft typography, and a structured layout typical for modern design systems.

The goal of this project is to highlight:

* High-quality adaptive layout
* Clean component-based structure
* Smooth visual presentation
* Production-ready static landing page

## 🌱 Features

* 📱 **Fully responsive layout** — mobile, tablet, desktop
* 🎨 **Modern, minimalistic design** — TailwindUI-style spacing & typography
* ⚡ **Lightweight and fast** — no frameworks, pure HTML/CSS/JS
* 🧩 **Structured sections** — hero, content blocks, branding elements
* 🖼 Smooth, visually appealing UI suitable for portfolio presentation

---

## 📘 Design Principles (Tailwind / Next.js Style)

* **Spacing scale**: consistent padding & gap system
* **Typography**: clean, readable content blocks
* **Color system**: minimal palette, focus on whitespace
* **Component thinking**: each visual block is independent
* **Responsiveness first**: mobile-first layout practices
